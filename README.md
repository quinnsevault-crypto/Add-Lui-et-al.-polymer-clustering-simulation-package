# Lui et al. (2013) polymer-clustering simulation

This repository contains the Python source used for the reduced, full-length simulation ensemble and the data and figures generated by that run. It is a reproducible model implementation, not a claim of exact numerical reproduction of every published figure.

## Completed ensemble

- Strains: MM32 and BB170.
- Conditions per strain: no-polymer control and P1, P2, and P3 at 7,000 a.u.
- Replicates: 10 independent random seeds per condition, for 80 runs total.
- Seeds: 42, 123, 456, 789, 1011, 1213, 1415, 1617, 1819, and 2021.
- Run duration: 0–30,000 a.u.; results recorded every 1,000 a.u.
- The final ensemble used a 100-a.u. operator-split tau-leap approximation. Binding and movement updates are batched; each bacterial cluster can move at most once per leap. Although an event-by-event Gillespie engine is also included, it was not the solver used for these 80 long runs.

The polymer concentration conversion is an implementation assumption: 100 a.u. per point-polymer agent, so 7,000 a.u. is represented by 70 lattice polymers. The supplementary information does not specify this conversion.

## Files

- `grid_env.py` — lattice, bacteria, polymer, and signal entities.
- `gillespie_engine.py` — event-by-event stochastic binding and movement engine.
- `biological_response.py` — growth, BB170 signal production, expression, and luminescence.
- `run_simulations.py` — general simulation runner and ensemble aggregation utilities.
- `run_long_core.py` — driver for the completed 80-run tau-leap ensemble.
- `plot_report_figures.py` — creates the three grouped report figures from the ensemble summary.
- `final_run_configuration.json` — settings and seeds recorded for the completed ensemble.
- `results/replicate_results.csv` — raw time-series data for all 80 runs.
- `results/ensemble_summary.csv` — means, standard deviations, and paired-control fold changes.
- `results/CORE_ENSEMBLE_REPORT.md` — run summary, endpoint values, and interpretation limits.
- `results/figures/` — the two strain time-course figures, endpoint comparison, and figure legends.

## Run it again

Use Python 3.10 or later. From this directory, install the listed dependencies and run:

```powershell
python -m pip install -r requirements.txt
python run_long_core.py
```

The driver uses the recorded seed list and writes checkpoints, raw data, ensemble summaries, and diagnostic plots to `long_core_results/`. Completed checkpoints are reused if a run is interrupted and resumed. To regenerate the three grouped report figures after a run completes, use:

```powershell
python plot_report_figures.py
```

That plotting script reads `long_core_results/ensemble_summary.csv` and writes images to `long_core_results/report_figures/`. The already-generated figures and data from the completed ensemble are preserved under `results/`.

## Scope and limitations

This completed ensemble covers the two strains and the four conditions above only. It does not include the complete 0–7,000-a.u. concentration series or the 25-pair affinity sweep. The accelerated solver and assumed concentration-to-polymer mapping may affect binding, transport, and clustering, so the included plots should be interpreted as exploratory model predictions. They are not experimental measurements, and they should not be presented as exact reproductions of the paper's results.
